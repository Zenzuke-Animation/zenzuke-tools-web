en:
  name: Sync Shy Layers
  description: A dockable utility panel that synchronizes the 'shy' visibility status of layers from a
    source composition to one or more target compositions. Layers are matched across compositions by name.
  instructions: '1. Open or select at least two compositions in the Project panel.

    2. Run the script to open the panel.

    3. Choose your ''Source'' composition in the dropdown.

    4. Click ''Sync to All Targets'' to synchronize the shy status of layers matching by name.'
  timelineCreation: Modifies the shy property of matching layers in the target compositions. Does not
    create new elements.
  limitations: Layers must have matching names to be synchronized. Requires at least two compositions
    selected in the Project panel.
  typicalUses: Keeping multiple versions or precompositions clean and synchronized in large projects,
    locking down visibility structures across complex compositions.
es:
  name: Sincronizar Capas Shy
  description: Un panel dockable que sincroniza el estado de visibilidad 'shy' (oculto) de las capas desde
    una composición de origen a múltiples composiciones de destino, haciendo coincidir las capas por su
    nombre.
  instructions: '1. Abre o selecciona al menos dos composiciones en el panel de Proyecto.

    2. Ejecuta el script para abrir el panel.

    3. Elige la composición ''Origen'' en el menú desplegable.

    4. Haz clic en ''Sync to All Targets'' para aplicar el estado de ocultación a las capas de destino
    con el mismo nombre.'
  timelineCreation: Modifica la propiedad shy de las capas correspondientes en las composiciones de destino.
    No crea elementos nuevos.
  limitations: Las capas deben llamarse exactamente igual para sincronizarse. Requiere tener al menos
    dos composiciones seleccionadas en el panel de Proyecto.
  typicalUses: Mantener ordenadas y sincronizadas múltiples versiones o precomposiciones de un proyecto
    pesado, asegurando la misma visibilidad de capas de control en todas ellas.
