en:
  name: Marker Batch Render
  description: Adds segments of your composition to the Render Queue based on composition markers. Segments
    are defined from one marker to the next (or end of comp), with output filenames taken from the marker
    comments.
  instructions: '1. Run the script to open the panel.

    2. Enter or browse for the output folder path.

    3. Click ''Add to Render Queue''.

    4. Each segment between markers will be added as a separate render item with its comment as the file
    name.'
  timelineCreation: Adds render items directly to the After Effects Render Queue. Does not modify composition
    layers.
  limitations: Requires active composition markers. The output directory must already exist on your disk.
  typicalUses: Batch rendering multiple social media formats, versions, or shots from a single composition
    timeline using marker flags.
es:
  name: Renderizado por Marcadores
  description: Añade segmentos de la composición activa a la Cola de Render (Render Queue) basándose en
    los marcadores de la composición. Los segmentos van desde un marcador al siguiente, usando los comentarios
    de los marcadores como nombre de archivo.
  instructions: '1. Ejecuta el script.

    2. Escribe o selecciona la ruta de la carpeta de salida.

    3. Haz clic en ''Add to Render Queue''.

    4. Cada tramo entre marcadores se añadirá a la cola de renderizado con su comentario correspondiente
    como nombre de archivo.'
  timelineCreation: Genera ítems de renderizado directamente en la cola de render (Render Queue). No añade
    elementos a la composición.
  limitations: La composición debe tener marcadores activos. La carpeta de destino debe existir previamente
    en el disco.
  typicalUses: Exportar múltiples planos, variaciones o formatos para redes sociales desde una única línea
    de tiempo usando marcadores como delimitadores.
