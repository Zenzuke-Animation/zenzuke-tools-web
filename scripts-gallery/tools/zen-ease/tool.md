en:
  name: Zen Ease
  description: A premium cubic Bezier curve editor extension for After Effects. It allows custom easing
    handle adjustments in a web canvas interface and applies calculated speed and influence coordinates
    directly to selected keyframes, with shape, color, and curved spatial path estimations.
  instructions: '1. Install the extension using a ZXP manager (e.g. ZXP Installer or Anastasiy''s Extension
    Manager).

    2. Open After Effects and go to Window > Extensions > Zen Ease.

    3. Adjust the Bezier curves in the editor canvas, or select a preset from the library tab.

    4. Click ''Apply to AE'' to ease selected keyframes, or ''Get from AE'' to load easing curves from
    existing keyframes.'
  timelineCreation: Applies spatial and temporal keyframe easing adjustments directly to active keyframes.
    No new elements are created.
  limitations: Requires enabling scripting file writes in preferences (Preferences > Scripting & Expressions
    > Allow Scripts to Write Files). Works with Bezier keyframe types.
  typicalUses: Crafting smooth, organic motions, animating complex rigs with custom easing templates,
    and saving/loading personal easing presets.
es:
  name: Zen Ease
  description: Una extensión premium de edición de curvas Bezier cúbicas para After Effects. Permite ajustar
    controladores de aceleración en un lienzo visual y aplicar velocidades e influencias calculadas directamente
    a los fotogramas clave seleccionados, adaptándose a color, formas y trayectorias espaciales.
  instructions: '1. Instala el paquete ZXP utilizando un gestor de extensiones (como ZXP Installer o Anastasiy''s
    Extension Manager).

    2. Abre After Effects y ve a Ventana > Extensiones > Zen Ease.

    3. Ajusta las curvas Bezier en el panel de edición, o elige un ajuste preestablecido (preset) de la
    pestaña de biblioteca.

    4. Haz clic en ''Apply to AE'' para aplicar aceleraciones a tus fotogramas clave, o ''Get from AE''
    para cargar la curva de fotogramas clave seleccionados.'
  timelineCreation: Aplica aceleraciones espaciales y temporales a los fotogramas clave seleccionados.
    No genera nuevas capas ni objetos.
  limitations: Requiere tener activa la casilla 'Permitir a las secuencias de comandos escribir archivos
    y acceder a la red' en las preferencias de After Effects. Funciona con fotogramas clave de tipo Bezier.
  typicalUses: Crear movimientos fluidos y orgánicos, animar rigs complejos con plantillas de aceleración
    y guardar/compartir bibliotecas de presets personalizados.
